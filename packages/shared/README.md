# Darbot Shared SDK Utilities

`@darbotlm/shared` is a private supporting workspace for the local Darbot SDK.
It provides shared contracts, schema adapters, errors, and utility functions.

Install and build it through the monorepo with `bun install --frozen-lockfile`
and `bun run build:sdk`. Internal dependencies use `workspace:*`.

Source revisions and adaptations are recorded in `packages\source-provenance.json`.
The original MIT copyright and license notices are retained in `LICENSE`.
