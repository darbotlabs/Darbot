# Darbot A2UI Renderer

`@darbotlm/a2ui-renderer` is the private A2UI implementation workspace for Darbot.
It provides the React and Lit rendering support, catalogs, actions, and message
types used by the application's generative UI.

Run `bun install --frozen-lockfile` and `bun run build:sdk` from `E:\Darbot`.
Application imports use `@darbotlm/a2ui-renderer`, including `Catalog` and
`basicCatalog`.

This package is implemented here, not installed through a registry alias.
Source revisions and adaptations are recorded in `packages\source-provenance.json`.
The original MIT copyright and license notices are retained in `LICENSE`.
